description: Interactive design refinement using Socratic method
---

Switch to superroo-architect mode and use the brainstorming workflow:

1. Check current project state (files, docs, commits)
2. Ask questions ONE AT A TIME to refine the user's idea
3. Propose 2-3 different approaches with trade-offs
4. Present design incrementally (200-300 word sections)
5. Write design document to `docs/plans/YYYY-MM-DD-<topic>-design.md`
6. Commit design document

Apply YAGNI ruthlessly - remove unnecessary features from all designs.
